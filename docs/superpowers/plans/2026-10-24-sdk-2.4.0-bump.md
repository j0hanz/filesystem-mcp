# MCP SDK 2.4.0 bump implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move `@modelcontextprotocol/server` and the test client from 2.3.1 to 2.4.0, and `@modelcontextprotocol/node` from 2.1.1 to 2.1.2. Pin the five example apps and the docs to the same client version.

**Architecture:** A dependency change. The only `src/` edit is one comment that 2.4.0 makes false. Task 1 bumps the root pins and lockfile, fixes that comment, and updates the CHANGELOG and one docs line. Task 2 re-pins the example apps and regenerates their lockfiles, as `examples/AGENTS.md` requires.

**Tech Stack:** Node 24, npm, `node:test`, `@modelcontextprotocol/server` 2.4.0.

**Spec:** the SDK release notes of 2026-10-23:
[server@2.4.0](https://github.com/modelcontextprotocol/typescript-sdk/releases/tag/%40modelcontextprotocol%2Fserver%402.4.0),
[client@2.4.0](https://github.com/modelcontextprotocol/typescript-sdk/releases/tag/%40modelcontextprotocol%2Fclient%402.4.0),
[node@2.1.2](https://github.com/modelcontextprotocol/typescript-sdk/releases/tag/%40modelcontextprotocol%2Fnode%402.1.2).

server and client 2.4.0 are minor releases. Their new features are the Skills extension (SEP-2640) and optional `params` on `ServerEvent` for the server, and `scopeForRefresh` for the client. This server uses none of them. node 2.1.2 is a patch release.

On 2026-10-24 the bump was run in a scratch copy of `381ca23e`:

- With exact pins, `npm run check` passed on Windows (Node 24.22.1).
- The contract snapshot did not change, and `--print-config` reported the new pins.
- The `fsq`, `gatekeeper`, `hooks` and `tail` example checks printed `check: ok` on Windows. `browser` printed it in WSL.

  1. `git fetch origin`

## Review Focus

Each item is a behavior that 2.4.0 touches. Existing tests already pin each one, so no task adds a test. Task 1 Step 3 runs each named test.

- **GET or DELETE `/mcp`** still answers 405 with `Allow: POST, OPTIONS` and JSON-RPC `-32000`. Pinned by `__tests__/http-server.test.ts:313`.
- **A `subscriptions/listen` with an unknown protocol version** (`1900-01-01`) is still refused with `-32022`, because 2.4.0 changed when `-32022` is sent. Pinned by STDIO-011 (`__tests__/stdio.test.ts:794`).
- **A modern listen stream still receives `notifications/resources/updated`** after 2.4.0 added `params` to `ServerEvent`. Pinned by `__tests__/subscriptions-listen.test.ts`.
- **`--print-config` reports exact pins**, now `2.4.0` / `2.1.2` / `2.0.2`. `__tests__/cli.test.ts:115` pins the server pin. The `--print-config` run in Step 3 checks node and express.
- **The advertised tools, prompts, resource templates and capabilities do not change.** Pinned by `__tests__/contract.test.ts`.
