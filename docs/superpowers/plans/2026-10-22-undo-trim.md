### Task 1: Keep an abandoned capture's charge until the call ends, drop the live-capture cap

Spec: finding 1 and side finding 1. Today `abandon()` returns the capture's whole pool charge while a sibling read may still be in flight, and the cap of 8 live captures is what bounds that. Once `abandon()` keeps the charge until `endCapture()`, the cap bounds nothing.

### Task 2: Preview folders moved more than once, and folder moves under a moved parent

Spec: side findings 2 and 3. Both live in the `rename` case of `restoreEntry` (`src/core/undo.ts:686-760`). They affect dry runs only.

- Side finding 3: a relocation is pushed only when the `to` folder was read from disk (`toIsRealDir`). When the simulation already placed a folder at `to` (`toKnown === 'dir'`), no relocation is pushed, so a folder moved twice previews an edit inside it as SKIPPED.
- Side finding 2: `assertTreeKeepsPolicy` lists `record.to`, not `disk(record.to)`, so after a parent folder moved it reads a path that is not on disk and refuses.

**Files:**

- Modify: `src/core/undo.ts:434-463` (`assertTreeKeepsPolicy`), `:696-751` (the `rename` case)
- Test: `__tests__/undo.test.ts`, `describe('restoreEntry')`, after the test `'dry run: a file edit inside a directory that was later moved previews as restored'`

**Interfaces:**

- Consumes: nothing from Task 1.
- Produces: `assertTreeKeepsPolicy(fs: GuardedFileSystem, listedAt: string, from: string, to: string): Promise<void>` (module-private). It lists entry names under `listedAt` and refuses when `isSensitive(join(from, name)) !== isSensitive(join(to, name))` for any name, including `''`. The refusal keeps its message and its `to` path argument.

```ts
const dryRunAll = async (entries: UndoEntry[]) => {
  const simulated = new Map<string, string | null>();
  const relocations: [string, string][] = [];
  const results = [];

it('dry run: an edit inside a folder moved twice previews as restored', async () => {
```

```ts
it('win32 only: a deleted directory junction comes back as a junction to the same folder', async (t) => {
  if (process.platform !== 'win32') {
    t.skip('junctions are win32 only');
    return;
  }
  const fsPromises = await import('node:fs/promises');
  const target = join(tmpDir, 'junction-target');
  const link = join(tmpDir, 'junction-link');
  await mkdir(target, { recursive: true });
  await fsPromises.symlink(target, link, 'junction');
  const before = await fsPromises.readlink(link);
  const entry = await captureOne((fs) => fs.rm(link));
  const outcome = await restoreEntry(entry, newFs(), { dryRun: false });
  assert.deepStrictEqual(outcome.remaining, []);
  assert.strictEqual(await fsPromises.readlink(link), before);
  assert.ok((await fsPromises.stat(link)).isDirectory());
});
```
