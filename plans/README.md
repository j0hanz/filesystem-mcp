## Findings considered and rejected

From the 2026-11-11 standard audit at `ab54a253`. Scope: source changed since
the audit at `d799cc5e` (text matching, batch, confirmation, create, delete,
move, diff), plus what that audit skipped (`stdio.ts`, `resources.ts`,
`watcher-registry.ts`, `store.ts`, `cursor.ts`, `schema.ts`, `outbound.ts`,
the undo dry-run preview, the release, scorecard and tdqs workflows,
`examples/`). Four read-only agents; every cited line re-read by the advisor;
nothing reproduced by running the server.

- Shutdown clears its forced-exit timer once `close()` resolves
  (`src/index.ts:64-66`): no handle was found that outlives `close()`.
- The undo preview's lock fallback skipping `assertWritable`
  (`src/core/undo.ts:1030-1039`): no call sequence reaches it; read-only
  folders are fixed at startup and records are validated when captured.
- `edit` refusing `oldText` that begins with U+FEFF when the bare text
  matches twice (`src/tools/edit.ts:564-574`): the bare text does match
  twice, so the ambiguity is real.
- A literal needle `a\nb` not matching `a\r\nb` in a mixed-ending file while
  the regex does (`src/core/matcher.ts:549-558`): recorded in `CHANGELOG.md`;
  plan 096 records it in the glossary and ADR-013 too. Not a code change.
- Checked and found correct: cursor tampering (query key and snapshot id are
  checked), `TtlLru` byte accounting, `jsonByteBound` as an upper bound, URI
  dot segments and `%00` (re-validated by the guard), batch result order and
  abort handling, diff counts against patch text, the undo preview never
  writing to disk or the journal, size limits counted in UTF-8 bytes after
  CRLF and BOM restore in all three Rewrite tools, zero-length and astral
  stepping in the matcher, version sync across the five manifests, the
  release gate's four `Check (...)` names against `ci.yml`.
- `npm audit --omit=dev`: 0 vulnerabilities.
- Not audited in this run: `src/transport/http.ts`, `http-policy.ts`,
  `scan.ts`, `glob.ts`, most of `fs.ts` and `path.ts` outside the cited
  blocks, `eslint.config.mjs`, the demo scripts, the Python example, the full
  text of `README.md` and `docs/configuration.md`. Build, lint and tests were
  not run.
