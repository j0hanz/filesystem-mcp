From the 2026-09-26 full audit at `8c2a82cd` (not selected; effort M):

- **Directory move/copy carries files out of path-based deny rules.**
  `validateTransferSource` (`move.ts:401-409`) checks only the directory's
  own path; `fs.cp` / `rename` move the whole tree. Operator patterns like
  `secrets/**` and the built-in `.aws/credentials` are path-based, so
