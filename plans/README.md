## Found but not planned (available for a later run)

  (`src/core/watcher-registry.ts:199` watches the file inode; the server's own
  writes rename over it). MED confidence — not reproducible on Windows.
- Batch `read` pre-estimates full file size for head/tail/range reads and
  skips every later file once one overflows (`src/tools/read.ts:211,241`).
  Reproduced.
- Path schema rejects legal names containing `..`, `;`, `|`, or a backtick
  (`src/core/schema.ts:44,72`). Reproduced with `v1..2.md`.
- Release-only paths (MCPB pack, Smithery dry run, Docker build) are not
  exercised before the release job tags and publishes (`release.yml:127`).
- No tests for `replace_text`'s `$`-expansion (`replace-text.ts:171`) or
  `move`'s EXDEV fallback (`move.ts:416`).
- `replace_text` computes each diff before checking the diff budget
  (`replace-text.ts:381`).
- An abort racing the atomic rename reports a completed write as failed
  (`src/core/fs.ts:98`).
- ADR line anchors drifted (all six in ADR-001).
